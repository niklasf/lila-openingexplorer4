# Samples

Small inputs for tests and trying out the pipeline and the servers.

## `lichess_db/`

The first whole games of the monthly dumps of https://database.lichess.org/,
with the same paths and file names (recompressed with `zstd -19`):

* `standard/`: 25,603 games of 2026-10.
* `antichess/`, `atomic/`, `chess960/`, `crazyhouse/`, `horde/`,
  `kingOfTheHill/`, `racingKings/`, `threeCheck/`: 2,236 to 6,025 games
  each (7 MB of PGN) of 2026-10.
* `broadcasts/`: 9,119 games of the 2026-09 broadcast dump (not indexed
  yet: no lichess game ids, rounds of over-the-board events).

## `masters-db/games/`

Made-up games in the layout of the masters database (`games/yyyy/mm/dd.pgn`,
`xx` for unknown month or day, the same headers, `FEN` and `SetUp` for
chess960 start positions): random names, events, dates and ratings, legal
random moves, results matching mates. Generated by
`cargo run --release --example gen_masters_sample -- samples/masters-db/games`.

```sh
masters_to_parquet samples/masters-db/games --out masters.parquet --legacy-ids <(echo deterministic,legacy)
```

## `requests/`

The busiest hour (2026-11-06 15:20 to 16:20 UTC, 535,915 requests) of the
request log of the production explorer, for `stress_explorer`: tab separated
`$msec`, `$status`, `$request_time`, `$upstream_response_time`,
`$request_uri`. Only `/lichess`, `/lichess/history`, `/masters`, `/master`
and `/masters/pgn/{id}` requests, and only the query parameters the
explorers recognize. No `/player` requests.
